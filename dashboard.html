Как запускать

  1. Установи зависимости один раз: pip install requests beautifulsoup4
  2. Запускай каждый день: python scraper.py
  3. Обнови эту страницу в браузере — появятся новые вакансии
  4. Для автозапуска на Mac/Linux добавь в cron: 0 9 * * * python /путь/к/scraper.py
